# Que:- Interview Explanation Of The Project
## Ans:- I developed and deployed a three-tier web application using Docker Compose. The architecture consists of Nginx as the presentation layer, Node.js as the application layer, and MySQL as the database layer. I created separate Docker containers for each service and configured Docker networks for communication between containers. I also implemented persistent storage using Docker volumes to preserve database data. Nginx acts as a reverse proxy and forwards API requests to the backend application. Finally, I performed application testing, checked container health, and troubleshot connectivity issues.
